# Project Documentation: ASP.NET Tiny Project

## Project Title
**Apex Auto - Car Showroom Management System**

## Project Description
Apex Auto is a tiny, functional ASP.NET web application developed to manage automobile showroom operations. It demonstrates a complete implementation of essential database interactions using ASP.NET. The project provides a simple and intuitive interface to manage showroom data efficiently.

## CRUD Operations Implemented
This project successfully fulfills the requirement of implementing basic CRUD operations:

1. **Insert (Create):** 
   - Users can add new cars to the showroom inventory.
   - Form fields include Car Make, Model, Year, Price, and Status.
   
2. **View/Display (Read):** 
   - The application fetches data from the SQL Server database and displays it dynamically on the dashboard.
   - Users can view a complete list of available cars and employee details.

3. **Update:** 
   - Existing vehicle details can be modified. For example, updating the price of a car or changing its status from 'Available' to 'Sold'.

4. **Delete:** 
   - Records of sold vehicles or former employees can be safely deleted from the system to maintain an updated database.

## Technologies Used
- **Frontend/Backend:** ASP.NET (C#)
- **Database:** SQL Server

## Setup & Execution
1. Clone the repository from GitHub.
2. Open the project in **Visual Studio**.
3. Create the database in SQL Server using the provided `CSM Schema.sql` script.
4. Build and Run the project using IIS Express. The application will launch in your default web browser.
